# NexusAI Research Intelligence Workbench

> **Tagline**: *Research. Verify. Connect. Decide.*  
> **Version**: 1.0.0 Production Release

NexusAI Research Intelligence Workbench is an enterprise-grade AI-powered analytical research platform designed for verifiable evidence synthesis, algorithmic conflict resolution, multi-specialist orchestration, and auditable decision support.

---

## 🗺️ NexusAI Feature Map

```
NEXUSAI RESEARCH WORKBENCH
│
├── Research Desk            (Active investigation workstation & prompt trigger)
│
├── Analysis Runs            (Restorable investigation history: 0248, 0247...)
│
├── Evidence Library         (38 indexed primary literature DOIs & datasets)
│
├── Research Modules         (Apex, Nova, DataPulse, Vortex task contracts)
│
├── Knowledge Index          (Vector search across 12,482 documents with filters)
│
├── Failure & Recovery       (8 scenario automated resilience testing suite)
│
├── System Validation        (Phase 11 automated 24 pipeline stage tests)
│
├── Evidence Graph           (Phase 15 interactive provenance node diagram)
│
├── Audit Trail              (Phase 12 timestamped auditable research log)
│
└── Research Dossier         (Phase 17 professional 16-section PDF export)
```

## ⚡ Quick Start

### 1. Frontend Setup
```bash
npm install
npm run dev
```
Open [http://localhost:5174/](http://localhost:5174/) in your browser.

### 2. Production Build Check
```bash
npm run build
```

### 3. FastAPI Backend Setup
```bash
cd backend
pip install -r requirements.txt
python main.py
```

### 4. Docker Cloud Deployment
```bash
docker-compose up --build
```
